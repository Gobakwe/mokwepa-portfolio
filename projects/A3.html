Obstacle-Avoiding / Behavior-Based Robot

Problem

How can a robot be modeled with both dynamics + kinematics, and how can a fuzzy controller regulate wheel drive force to achieve a desired speed while safely stopping near an obstacle?

Solution

Simulink model of a two-wheeled robot with wheel subsystems, speed aggregation, heading integration, and an 'alert' subsystem for obstacle distance.

Methodology

  • Designed a Mamdani Fuzzy Inference System (FIS).
  • Inputs: speed_error and distance_to_obstacle.
  • Output: net_drive_force.
  • Logic: min for AND, max for OR, centroid defuzzification.

Results

  • With obstacle at (0.5, 0): robot stops at approx x ≈ 0.47.
  • Effective deceleration before reaching the obstacle confirmed.

Tools Used

MATLAB/Simulink, Fuzzy Logic Control
