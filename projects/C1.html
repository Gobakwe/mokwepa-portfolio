Intelligent Perception (Vision/OCR)

Banknote Serial Number Extraction

Problem

How can banknote serial numbers be reliably detected and recognized under real-world imaging conditions and converted into traceable data?

Solution

Two-stage detect -> recognize pipeline: Capture -> Detect Serial -> CRNN/TrOCR recognition -> Validation -> Cloud Storage.

Methodology

  • Data collection & labeling (Botswana-banknote dataset).
  • Preprocessing & augmentation (resize, rotation, noise).
  • Serial-region detection (SegLink with DenseNet).
  • Sequence recognition (CRNN-CTC and TrOCR lanes).
  • Embedded + cloud workflow integration (ESP32, Pi, Cloud).

Results

  • Primary metrics: Character Error Rate (CER) and sequence accuracy.
  • Robustness to wear, rotation, low contrast.
  • System-level reliability.

Tools Used

SegLink, CRNN/TrOCR, Python, ESP32, Raspberry Pi, FastAPI
