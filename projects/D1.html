Leak Detection & Monitoring Web App

Problem

How can near-real-time incident data be streamed, analyzed for anomalies, and visualized on an interactive map?

Solution

Full-stack monitoring web app: React UI + Leaflet maps + Flask API.

Methodology

  • Design event schema.
  • Implement ingestion + simulation.
  • Apply anomaly detection logic.
  • Visualize events geographically.
  • Provide simple API.

Results

  • Map responsiveness.
  • Correctness of severity rendering.
  • Latency/stability of streaming.

Tools Used

React, Flask, Leaflet, REST API
